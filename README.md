# StoryVision v2

🔗 **Demo:** https://storyvision-eight.vercel.app

Plataforma que ensina storytelling com dados e ajuda a transformar os seus dados em um roteiro de apresentação.

Reescrita do [StoryVision v1](https://github.com/vali2107/storyvision-v1).

- Vocabulário do domínio: [GLOSSARY.md](./GLOSSARY.md)
- Decisões de arquitetura: [docs/adr](./docs/adr)

## Rodando localmente

```bash
npm install
npm run dev
```

Abra http://localhost:3000.
